# Khel Mahakumbh Mascot Club

A public, mobile-friendly library of 44 mascot stickers and 35 animated GIFs, covering reactions, gestures, celebrations and ten sports.

Open `index.html` or serve this directory with a static web server. Deploy the repository root to GitHub Pages. No build step or account login is needed for visitors.

Assets are available individually and in ZIP packs under `downloads/`. GIFs are frame-by-frame illustrated loops with visible stepping and some detail variation. Downloading a PNG provides an image file; installing it in a messaging application's sticker tray may require that application's sticker creator.

The site includes no analytics, third-party scripts, forms or server-side code. Its Content Security Policy allows local assets only. Automated browser checks were performed; a HawkScan DAST scan was unavailable because its runtime/authentication prerequisites were not configured.
